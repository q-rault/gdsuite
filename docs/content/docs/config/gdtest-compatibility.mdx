---
title: gdtest.toml compatibility
description: When gdtest.toml is still useful and why gdsuite no longer depends on it.
---

`gdtest.toml` remains a normal `gdtest` config file. Users can still run
`gdtest` directly.

For `gdsuite`, it is a compatibility file rather than part of the normal suite
contract.

## What `gdsuite` uses instead

`gdsuite` should read `gdsuite.toml` for suite workflows, including the
`gdtest`-related settings that matter to `gdsuite test` and `gdsuite check`.

## When `gdtest.toml` still matters

- when you run `gdtest` directly
- when `gdsuite init` imports settings from an older repository

## What `gdsuite` does not assume

- it does not require `gdtest.toml` to exist
- it does not keep `gdtest.toml` aligned with `gdsuite.toml`
- it does not read `gdtest.toml` as a runtime fallback during normal suite use
