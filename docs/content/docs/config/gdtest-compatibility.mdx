---
title: gdtest.toml compatibility
description: Which gdtest config areas stay product-owned and which ones gdsuite expects to keep aligned.
---

`gdtest.toml` remains a normal `gdtest` config file. Users can still run `gdtest` directly.

## Suite-owned expectations

- suite-aligned test discovery patterns
- CI profile wiring such as `profile.ci.reporter`
- other shared defaults required for `gdsuite test` and `gdsuite check --profile ci`

## Product-owned areas

- advanced harness and runtime behavior
- filters, jobs, and product-specific execution details
