---
title: gdtypecheck Overview
description: How gdsuite typecheck uses gdtypecheck, and what it reports.
---

`gdtypecheck` reports GDScript compile errors, including type errors, shader
compile errors, and references to files that no longer exist, by loading the
project in a headless Godot. In the suite it runs as `gdsuite typecheck` and
as the typecheck step of `gdsuite check`.

```sh
gdsuite typecheck                   # the whole project
gdsuite typecheck -- --strict       # arguments after -- go to gdtypecheck
```

gdtypecheck has no settings file: everything is a flag.
