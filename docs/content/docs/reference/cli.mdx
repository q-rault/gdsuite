## Core commands

- `gdsuite init [--output pretty|plain]`
- `gdsuite migrate`
- `gdsuite setup [--sync-product-configs] [--output pretty|plain]`
- `gdsuite doctor [--output pretty|plain|json]`
- `gdsuite fmt [--check]`
- `gdsuite lint [--fix] [--unsafe-fixes] [--report text|json]`
- `gdsuite typecheck`
- `gdsuite test [--report text|json] -- ...`
- `gdsuite health [--report text|json] -- ...`
- `gdsuite check [--fix] [--no-fmt] [--no-lint] [--no-typecheck]`
- `gdsuite report [latest|check|test|health|ci]`

## Common CI commands

```bash
gdsuite doctor --output json
gdsuite check
gdsuite test --report json
gdsuite health --report json
gdsuite report ci
```

## Check contract

`gdsuite check` is the fast static gate. Its intended stable meaning is:

- formatting
- linting
- GDScript type checking

It is not the place where `test`, `health`, profiles, or CI composition are hidden.

## Text output modes

- `pretty` is the default for `init`, `setup`, and `doctor`
- `plain` keeps stable prefixed text lines for logs and shell scripts
- `json` is currently supported by `doctor`

## Delegated command examples

```bash
gdsuite test -- --filter combat
gdsuite health -- --format json
```
