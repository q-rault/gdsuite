## Core commands

- `gdsuite init`
- `gdsuite migrate`
- `gdsuite setup [--sync-product-configs]`
- `gdsuite doctor`
- `gdsuite fmt [--check]`
- `gdsuite lint [--fix] [--unsafe-fixes] [--report text|json]`
- `gdsuite typecheck`
- `gdsuite test [--report text|json] -- ...`
- `gdsuite health [--report text|json] -- ...`
- `gdsuite check [--profile <name>] [--report text|json]`
- `gdsuite report [latest|check|test|health|ci]`

## Important corrections

- There is no standalone `gdsuite ci` command.
- `gdsuite init` is the primary first command for a new project.
- `gdsuite migrate` is the adoption path for an existing repo.
- `gdsuite doctor` reports drift warnings against suite-owned product config invariants.
- `gdhealth` is a first-class workflow surface, not an optional appendix.

## CI commands

```bash
gdsuite check --report json
gdsuite test --report json
gdsuite health --report json
gdsuite report ci
```

## Delegated command examples

```bash
gdsuite test -- --filter combat
gdsuite health -- --format json
```
