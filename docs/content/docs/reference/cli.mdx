## Core commands

- `gdsuite init`
- `gdsuite migrate`
- `gdsuite setup [--sync-product-configs]`
- `gdsuite doctor`
- `gdsuite fmt [--check]`
- `gdsuite lint [--fix] [--unsafe-fixes] [--report text|json]`
- `gdsuite typecheck`
- `gdsuite test [--report text|json] -- ...`
- `gdsuite health [--report text|json] -- ...`
- `gdsuite check [--profile <name>] [--report text|json]`
- `gdsuite report [latest|check|test|health|ci]`

## Common CI commands

```bash
gdsuite check --report json
gdsuite test --report json
gdsuite health --report json
gdsuite report ci
```

## Delegated command examples

```bash
gdsuite test -- --filter combat
gdsuite health -- --format json
```
