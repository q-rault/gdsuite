## Commands

| Command | What it does |
|---|---|
| `gdsuite init` | Write `gdsuite.toml` and install the toolchain |
| `gdsuite setup` | Install or repair the toolchain under `.gdsuite/` |
| `gdsuite migrate` | Move old settings files (`gdlintrc`, `gdformatrc`, `gdtest.toml`, `gdhealth.toml`, gdsuite 0.1 sections) into `gdsuite.toml` |
| `gdsuite doctor` | Print the resolved tool paths, versions and setup status |
| `gdsuite fmt` | Format the project with [`gdtidy fmt`](/gdtidy/formatting) |
| `gdsuite lint` | Lint the project with [`gdtidy lint`](/gdtidy/linting) |
| `gdsuite typecheck` | Run [gdtypecheck](/gdtypecheck) |
| `gdsuite test` | Run [gdtest](/gdtest) on `default_test_target` |
| `gdsuite health` | Run [`gdhealth health`](/gdhealth) |
| `gdsuite check` | Run the [check steps](/workflow-check) in order, stopping at the first failure |
| `gdsuite report [NAME]` | Print a saved report: `latest` (default), `check`, `test`, `health`, or `ci` to combine them |

## Flags

Every command takes:

| Flag | Default | Description |
|---|---|---|
| `--project-root <DIR>` | `.` | The Godot project |
| `--godot-exe <PATH>` | `godot_exe` in `gdsuite.toml`, then auto-discovery | Godot 4 binary |

And some take:

| Flag | Commands | Description |
|---|---|---|
| `--output pretty\|plain\|json` | `init`, `setup`, `doctor` | `pretty` (default) for people, `plain` for stable prefixed log lines, `json` for tools |
| `--report text\|json` | `lint`, `test`, `health`, `check` | Print the suite report as text or JSON, and save it under `reports/gdsuite/` |

## Passing arguments to a tool

Everything after `--` goes to the tool unchanged:

```bash
gdsuite fmt -- --check                    # gdtidy fmt --check
gdsuite lint -- --fix player/             # gdtidy lint --fix player/
gdsuite typecheck -- --strict             # gdtypecheck --strict
gdsuite test -- --filter combat           # gdtest --filter combat
gdsuite health -- health --fail-on critical
gdsuite health -- graph --format emerge-html --output graph.html
```

For `gdsuite health`, the arguments replace the default `health` subcommand, so
name the gdhealth subcommand first.

## Common CI commands

```bash
gdsuite setup --output plain
gdsuite doctor --output json
gdsuite check --report json
gdsuite test --report json
gdsuite report ci
```

See [CI](/ci) for a full workflow.
