---
title: Glossary
description: Short definitions for the terms that appear across suite, test, and health docs.
---

- Suite-owned: behavior or config that `gdsuite` must control to keep the workflow coherent.
- Product-owned: behavior or config that belongs primarily to `gdtest` or `gdhealth`.
- Delegated command: a `gdsuite` command that forwards into a product tool while keeping suite framing.
- Health bundle: the raw `gdhealth` artifact directory, separate from suite JSON envelopes.
- Drift: a mismatch between the current product config and suite-owned invariants expected by `gdsuite`.
